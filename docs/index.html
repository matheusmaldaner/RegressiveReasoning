Ten brands, one classifier.

A 10-class brand logo classifier built with TensorFlow and transfer learning from an EfficientNetV2-S backbone, trained and evaluated on UF's HiPerGator supercomputer. The model reaches 95% validation accuracy across logos from Nike to 3M.
